# 固定入场后的止盈与持仓期限对照

**结论：影响因入场而异，尚无证据把四类亏损共同归因于1R或24小时限制。布林回归改3R并延至72小时后少亏明显；均线交叉放大目标反而更差。全部144账户在完整历史和最近阶段仍亏损，未找到可采用的组合。**

## 实验边界

四种入场的全部事件、初始止损、方向、品种和执行时点直接复用上一轮冻结结果，未重新计算或添加过滤。UTC完整区间为2024-08-01至2026-10-25（结束时点不含）；最近阶段从2026-06-20开始，沿用同一连续账户及边界持仓。

每账户初始10,000 USDT，每笔风险预算0.5%，最多两仓，总风险及方向预算1%，总名义敞口不超过权益一倍。基础成本为每次成交名义本金0.1%手续费、2bps不利滑点；双倍成本为0.2%及4bps；延迟场景在基础成本上再晚15分钟。这些是研究假设，未核实为用户账户条款。资金费使用原始官方结算时点、费率、mark price及持仓数量。

四入场×四退出×三期限×三成本共144账户。期限96/288/672根15分钟分别为24/72/168小时，入场根计为第1根。原1R规则同根优先止损、2R目标、1R保护退出；固定2R/3R保留原始止损及全部数量。手续费保本价不保证覆盖退出滑点、资金费和跳空。

## 同期限换止盈与共同交易对照

1. **布林回归改善不全来自少交易。** 同为72小时，原1R规则净收益-42.63%，固定3R为-20.21%。400笔共同准入且成熟、入场时间/价格/初始止损相同的交易，平均每笔净收益比例改善0.193个百分点、净R改善0.09275；109笔改善、83笔恶化、208笔相同。成交数558降至417，账户总差异仍混有容量和定仓效应。固定3R从24延至72小时也有改善（-33.57%至-20.21%），继续延至168小时又退到-21.77%，不支持持有越久越好。

2. **均线交叉放大目标会损害本轮结果。** 同为24小时，原退出-20.87%，固定2R为-28.99%，两者都是262笔。258笔共同成熟交易平均差为-0.163个百分点、净R差-0.08261。不能认为1R统一截断了有价值的行情。

3. **通道突破要区分退出质量与少交易。** 同为168小时，原1R规则-31.53%，固定3R-31.12%，只改善0.414个百分点；成交663降到435，手续费少1,495.57 USDT。372笔共同交易反而平均恶化0.03596个百分点、净R差-0.04796。账户少亏不能全部解释为共同交易的退出更有效。

共同交易配对只覆盖两个账户都准入的成熟交集，不能代表全部机会。成熟截止固定为event.signal_time <= 结束时点−673根15分钟，排除最长672根持仓及额外1根延迟的尾部不成熟影响；完整账户没有因此裁剪事件。
