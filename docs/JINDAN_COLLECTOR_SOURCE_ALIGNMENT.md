# 金丹 v1.0 采集器源码对齐

`jindan_live/` 保存线上金丹 v1.0 采集器的源码，`deploy/jindan-v1/` 保存对应的部署配置。采集器是独立的公开行情观察服务，不提交订单。

冻结的 `prospective-plan.json` 和 `record-catalog.json` 保留在 VPS 的 `jindan-release/v1-20261029/collector/`，不随源码仓库同步。采集器启动回执绑定原始冻结计划及源码的哈希；脱敏、重排或重新序列化的文件不能替代原始冻结输入。需要构建或恢复时，应在隔离构建目录使用 VPS 上的原件并校验哈希，同时保留已有激活回执和状态。

`runtime/jindan-v1/` 包含运行状态和数据，不能作为源码同步，也不能在对齐时覆盖。源码同步不会自动重启采集器；修改代码、重建镜像或重启服务前，须另行检查冻结合同、线上状态和现有授权。
